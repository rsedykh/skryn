Installation.

  1. 1Download Skryn.zip from the latest release.
  2. 2Unzip it and drag Skryn.app to Applications.
  3. 3Open it. macOS blocks the first launch because Skryn isn't notarized: go to System Settings → Privacy & Security and click Open Anyway.On macOS 14, right-click → Open works too.
  4. 4Grant Screen Recording permission when asked.

Updating

Since v0.1.6, Screen Recording permission carries over when you update.

Updating from v0.1.5 or earlier? If screenshots stop working, reset it once:

  1. System Settings → Privacy & Security → Screen Recording
  2. Remove Skryn from the list
  3. Take a screenshot; Skryn asks for permission again
